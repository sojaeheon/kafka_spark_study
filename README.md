# 📚 Kafka & Spark Study

> ⚡ Kafka와 Spark를 활용해 안정적이고 확장 가능한 실시간 데이터 파이프라인을 구축하기 위한 학습 기록입니다.

강의에서 배운 내용을 **직접 이해한 표현으로 다시 설명하고**, 예제 코드와 실습 과정에서 얻은 경험을 정리합니다.

## 🧭 학습 방향

이 저장소에서는 단순히 도구의 사용법을 익히는 데 그치지 않고, 다음 질문에 답하는 방법을 공부합니다.

- 실시간 데이터는 어떻게 수집하고 처리해야 하는가?
- 데이터와 트래픽이 증가하면 파이프라인을 어떻게 확장해야 하는가?
- 일부 서버에 장애가 발생해도 서비스를 계속 운영하려면 어떻게 해야 하는가?
- 처리량과 안정성을 높이기 위해 Kafka와 Spark를 어떻게 구성해야 하는가?
- 운영 중인 데이터 파이프라인의 상태와 지연을 어떻게 관찰해야 하는가?
- 코드 변경부터 배포까지의 과정을 어떻게 자동화해야 하는가?

## 🎯 학습 목표

학습을 마친 뒤 다음을 할 수 있는 상태를 목표로 합니다.

- [ ] Kafka의 핵심 구성 요소와 데이터 전달 과정을 설명한다.
- [ ] Producer와 Consumer를 구현하고 주요 설정을 조정한다.
- [ ] Spark Streaming으로 실시간 데이터를 처리한다.
- [ ] Kafka와 Spark를 연동한 데이터 파이프라인을 구성한다.
- [ ] 처리량, 지연 시간, 안정성 사이의 트레이드오프를 설명한다.
- [ ] 모니터링 지표를 바탕으로 장애와 성능 문제를 분석한다.
- [ ] AWS에 처리 결과를 저장하고 필요한 데이터를 조회한다.
- [ ] 코드 변경부터 배포까지의 과정을 자동화한다.
- [ ] 클러스터의 일부 장애가 전체 시스템에 미치는 영향을 검증한다.
